# 🎮 Roblox Profile Website

This is my first HTML & CSS project.

I built this website while learning web development from scratch. The goal of this project was to practice HTML, CSS, layouts, Flexbox, hover effects, gradients, and creating a clean profile page.

## ✨ Features

- 🎮 Roblox profile page
- 🖼️ Profile avatar
- 🌈 Gradient background
- 💙 Glow effects
- 🎨 Modern game cards
- ✨ Hover animations
- 📱 Clean layout
- 🔗 Roblox profile button
- 🧭 Navigation bar
- 👣 Footer

## 🛠️ Built With

- HTML5
- CSS3
